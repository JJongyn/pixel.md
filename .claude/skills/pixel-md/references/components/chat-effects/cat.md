# Cat nap

Add a small pixel cat that perches on the input rim. While idle, it sleeps with both paws resting on the composer. While working, it holds a churro and eagerly licks it.

```html
<pixel-chat-effect variant="cat">
  <your-existing-chat-input></your-existing-chat-input>
</pixel-chat-effect>
```

Switch `variant` to `cat-working` while the agent is running and back to `cat` when it is idle. Import `pixel.md/chat-effect`. The animation pauses offscreen and for reduced-motion users.
